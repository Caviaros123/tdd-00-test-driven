npm install puis npm test pour les tests, npm start pour lancer le programme.

Il lit input.txt (ou un autre fichier passé en argument) et affiche les deux indicateurs, lecture A puis lecture B. Sur l’extrait du sujet ça donne 24 et 93.

Les lignes du fichier sont des points x,y séparés par " -> ", uniquement des segments horizontaux ou verticaux. Une ligne vide est ignorée, un point mal écrit ou un diagonal lève une erreur.
